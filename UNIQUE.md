# Uniqueness & Access Model

This repository is a **standalone, independent work** — not a fork,
not a copy, not a derivative of any other repository.

## How uniqueness is proven

Every release carries a `UNIQUE.json` containing:

| field            | meaning                                                   |
|------------------|-----------------------------------------------------------|
| `fingerprint`    | SHA-256 over `{tree_digest, commit, author, timestamp}`   |
| `tree_digest`    | SHA-256 over the canonical manifest of every tracked file |
| `commit`         | the git commit SHA at which the fingerprint was generated |
| `author`         | the operator identity that owns this work                 |
| `timestamp`      | the unix timestamp at generation                          |
| `schema_version` | the schema of the fingerprint document (currently `1`)    |

Any divergence in any tracked file, HEAD commit, author, or
timestamp changes the fingerprint. Two repos that look identical
in name cannot have identical fingerprints unless they are byte-
identical at the same commit — which is impossible after the
slightest modification.

### Verify

```bash
python3 tools/build_uniqueness.py --verify
# UNIQUE.json: OK (<24-hex-prefix>...)
```

The `--verify` flag re-derives the fingerprint from the current
working tree and compares it to the recorded `UNIQUE.json`. A
stale `UNIQUE.json` is reported as `STALE` and the script exits
non-zero.

### Regenerate

```bash
python3 tools/build_uniqueness.py --write
# rewrites UNIQUE.json from the current tree + HEAD
```

This is safe to run anytime; the script is idempotent on an
unchanged tree.

## One-way access

The repository has two layers. The boundary between them is
**cryptographically enforced** at runtime; it's not a convention.

### Public layer — `public/`

Generated by `python3 tools/build_public_index.py`. Contains:

* README, LICENSE, BRAND
* The selected, safe subset of `rollout_shield/` modules
* The selected docs and tests
* `UNIQUE.json` (the fingerprint itself)
* `INDEX.json` (per-file SHA-256 manifest of the public surface)

External consumers may:

* **read** any file under `public/`
* **copy** the public surface into their own works
* **verify** integrity using `INDEX.json` + `UNIQUE.json`

External consumers **may not**:

* reach anything outside `public/` — there is no relative path
  that escapes it
* read private keys, identity chains, audit logs, plans, or
  recovery phrases — those are hard-excluded by `EXCLUDE_DIRS`
  and `EXCLUDE_GLOBS` in `tools/build_public_index.py`
* mint, replay, or alter identity events — see `INTERNAL.md`

### Internal layer — everything not in `public/`

This includes:

* `keys_material/` — private signing keys (mode 0600)
* `identity/chain.jsonl` — the pseudonym chain (mode 0600)
* `identity/conflicts.jsonl` — user↔AI disagreements (mode 0600)
* `access/*.jsonl` — append-only access audit log (mode 0600)
* `state/` — runtime state roots
* `.beads/` — local issue tracking and agent memory
* `tools/secure_state.py`, `tools/safeup.py` — recovery / snapshot
* plans, paper phrases, recovery phrases, `.seed`, anything
  matching `*.pem`, `*.key`, `*backup*`, `*secret*`, etc.

Reaching any of these from outside is impossible without the
operator's identity token. The runtime checks this at every call
site (see `rollout_shield/unique.py`).

## What this means in practice

* If you find this repo on the public internet, what you see is
  the public surface — by design.
* The full source is held by the operator and the operator's
  authorized model only.
* Forks of this repo will have **different** fingerprints and
  will be detected as such; if a fork claims to be this repo,
  `UNIQUE.json` is the proof.
* Copies that omit `UNIQUE.json` are incomplete; consumers can
  rebuild it with `tools/build_uniqueness.py --write`.
* The internal layer is signed into the identity chain at every
  state-mutating call (see `docs/IDENTITY.md`), so any unauthorized
  external mutation is auditable post-hoc.

## Threat model

| Threat                              | Mitigation                                |
|-------------------------------------|-------------------------------------------|
| Repo is silently forked              | UNIQUE.json fingerprint detects drift      |
| Public surface leaks an internal     | EXCLUDE_DIRS + EXCLUDE_GLOBS in build script |
| External caller hits an internal API | rollout_shield/unique.OneWayGate refuses    |
| Internal file copied to public       | chmod 0600 + runtime check on read         |
| Replay of old identity event         | hash-linked chain; verify() flags replay   |
| Operator forgets the seed            | seed is auto-generated; can be re-set      |
